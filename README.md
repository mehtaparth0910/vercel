# Bio-inspired Engineering — Green Theme (Vercel)

Static website themed in charcoal, forest green, sage, and warm ivory. Includes Overview, Simulation, Presentation, Citations, and Team tabs.

## Important presentation update
The Presentation tab embeds the exact 32-page PDF supplied for this update (`presentation.pdf`) and includes links to download or open it. The Team tab retains Adwita (C364), Hriday (C367), and Parth (C368).

## Deploy
1. Upload `index.html`, `vercel.json`, and `presentation.pdf` to your GitHub repository.
2. Import the repository at https://vercel.com/new.
3. Choose Other as framework preset; no build command is required.
4. Deploy.

The diagrams in Simulation are illustrative conceptual visuals, not measured engineering data.
